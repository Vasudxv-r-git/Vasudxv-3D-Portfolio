## Plan: Add Caveman and Ponytail Skills (User-Level)

### What
Install two custom skills to your user-level ZCode skills directory so they're available in every workspace.

### Steps
1. **Create the user-level skills directory structure:**
   - `C:\Users\Vasu's LOQ\.zcode\skills\caveman\`
   - `C:\Users\Vasu's LOQ\.zcode\skills\ponytail\`

2. **Create `C:\Users\Vasu's LOQ\.zcode\skills\caveman\SKILL.md`** — copy the content from `C:\Users\Vasu's LOQ\Downloads\Caveman.md` (the full caveman skill with frontmatter, rules, intensity levels, etc.)

3. **Create `C:\Users\Vasu's LOQ\.zcode\skills\ponytail\SKILL.md`** — copy the content from `C:\Users\Vasu's LOQ\.gemini\config\skills\ponytail\SKILL.md` (the full ponytail skill with frontmatter, the ladder, rules, etc.)

### Result
After this, both skills will be auto-discovered by ZCode and triggerable via `/caveman` and `/ponytail` in any workspace. No config file changes needed — ZCode auto-discovers skills from `<user>/.zcode/skills/*/SKILL.md`.
